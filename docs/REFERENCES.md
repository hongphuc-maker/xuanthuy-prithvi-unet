# Where each piece of code comes from

Every module re-states or ports existing, published code. Links are pinned to the exact
versions in `pyproject.toml` (TerraTorch 1.2.12, segmentation_models_pytorch 0.5.0,
timm 1.0.30) and to the commits of the completed runs, so the lines shown are the lines
that ran. The same links appear in the docstrings next to the code.
`tests/test_legacy_equivalence.py` proves the re-stated model computes the same function.
